# JARVIS Mobile · LAB

Отдельный экспериментальный Android-проект на Java и стандартных компонентах Android. Это не готовый релиз: проверена компиляция Java-исходников против локального Android SDK, но не сборка APK, установка или работа на телефоне.

## Что реализовано в исходниках

- Чат с OpenAI (Responses API) или DeepSeek; ручной выбор модели.
- Локальная история, одна заметка и список задач с отметкой выполнения.
- Ручная диктовка через установленный системный распознаватель и озвучка ответа через Android TTS.
- Передача истории, заметки или задач через системное меню «Поделиться».

Нет фонового распознавания, уведомлений о сроках, Outlook/Kerio, субагентов, вложений и синхронизации с настольным приложением. Наличие системного распознавателя и TTS зависит от устройства.

## Сборка

Откройте каталог `mobile/android` в Android Studio как Gradle-проект. Нужны JDK 17, Android SDK 35, Android Gradle Plugin 8.9.2 и Gradle 8.11.1. Gradle Wrapper пока не включён: используйте установленный Gradle либо настройку Gradle в Android Studio. Затем синхронизируйте проект и соберите debug APK. Минимальная версия Android — 8.0 (API 26).

## Первый тест

1. Без ключа проверьте заметку и задачи: создайте, закройте приложение, откройте снова.
2. Проверьте диктовку и системное меню экспорта.
3. В настройках выберите провайдера, модель и собственный API-ключ. Для DeepSeek укажите доступную модель, например `deepseek-chat`; модель OpenAI выбирайте по доступу вашего аккаунта.
4. Отправьте короткий запрос. Ошибки сети, авторизации и лимитов показываются отдельно; автоматических повторов нет.
5. Проверьте историю, озвучку и очистку. Поворот экрана/перезапуск требует повторного ввода ключа.

## Данные и расходы

Ключ хранится только в памяти текущего экрана приложения и не записывается в настройки. Не встраивайте общий секрет в APK. История, заметка и задачи хранятся локально без дополнительного шифрования; резервное копирование Android отключено. Не используйте прототип для чувствительных рабочих данных.

При отправке запроса провайдер получает сообщение и до 20 последних сообщений контекста. Облачные запросы могут тарифицироваться. Системная диктовка также может использовать интернет. OpenAI-запросы отправляются с `store: false`; это не обещание отсутствия всех серверных журналов. Закрытие приложения не гарантирует отмену уже принятого облачного запроса.

Использованные официальные справочники: [OpenAI: генерация текста](https://developers.openai.com/api/docs/guides/text), [Android Gradle Plugin 8.9](https://developer.android.com/build/releases/agp-8-9-0-release-notes), [RecognizerIntent](https://developer.android.com/reference/android/speech/RecognizerIntent).
