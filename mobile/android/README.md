# 📱 JARVIS Mobile · 1.0.0 LAB

Облегчённое приложение для Android 8.0 и новее. Это тестовая версия, а не проверенный менеджер паролей. Почта Outlook/Kerio и «Агенты · LAB» намеренно отсутствуют.

## Возможности

- Новости из выбранной HTTPS RSS-ленты и прогноз Open-Meteo на неделю.
- Заметки, локальные задачи, таймер, уведомления о напоминаниях и будущих днях рождения.
- Привычки с ежедневными отметками и дневник выполненных тренировочных подходов.
- Чат: DeepSeek или OpenAI, выбор модели, история, диктовка, озвучка и экспорт.
- Зашифрованный сейф: мастер-пароль, необязательная биометрия и зашифрованные резервные копии.
- Прямой обмен с новой компьютерной сборкой JARVIS по одной Wi-Fi сети.

## Установить APK

1. Откройте [Android-сборки](https://github.com/DIBERLOG/JARVIS_ALTRON/actions/workflows/android.yml), выберите последнюю успешную сборку.
2. В Artifacts скачайте `jarvis-android-1.0.0-mobile-lab` и распакуйте ZIP. GitHub может потребовать вход.
3. Перенесите `JARVIS-Mobile-1.0.0-lab.apk` на телефон и откройте. Разрешите установку из выбранного источника, затем отключите это разрешение.
4. Разрешите уведомления. Микрофон нужен для диктовки, камера — только для QR-кода. Сопряжение доступно и через вставку строки.

LAB-сборка подписывается тестовым ключом окружения. При смене ключа обновление поверх старого APK невозможно. **До переустановки экспортируйте данные и зашифрованный сейф:** удаление приложения стирает его локальные данные. Постоянная подпись нужна до стабильного распространения.

## Телефон ↔ компьютер

1. Подключите устройства к одной частной Wi-Fi сети. Гостевые сети с изоляцией клиентов не подходят.
2. На ПК: **Настройки → Данные и резервные копии → Синхронизация с телефоном**. Выберите локальный адрес и включите обмен. Старый установщик v1.0.0 этого раздела не содержит.
3. Разрешите брандмауэр только для частной сети. Не открывайте порт роутера в интернет.
4. На Android откройте «Синхронизация», отсканируйте QR-код или вставьте строку. Сверьте код и подтвердите устройство на ПК.
5. Нажмите синхронизацию. Автоматический обмен включается отдельно; Android может задерживать его ради экономии батареи.

Передаются заметки, напоминания, дни рождения, привычки и тренировки. История чатов включается отдельно. Таймер, быстрые задачи, кэш и настройки остаются локальными. ПК и JARVIS должны быть включены. Чтобы отменить доверие, отзовите устройство **на компьютере**: отключение на телефоне удаляет только локальное подключение.

### Сейф — отдельное согласие

Включите передачу сейфа отдельно на обоих устройствах. Мастер-пароль вводится локально и не передаётся; сервис принимает зашифрованный контейнер. API-ключи не синхронизируются. При конфликте проверьте обе версии; объединение требует общего мастер-пароля. Смена мастер-пароля может потребовать ручного восстановления из резервной копии.

Используется совместимый с ПК формат AES-256-GCM / PBKDF2. Соединение использует TLS с привязкой сертификата к QR-коду. Это описание реализации, **не независимый аудит безопасности**. Сначала используйте вымышленные пароли. Новый мобильный сейф не показывает отдельный код восстановления: сохраните мастер-пароль и зашифрованную копию. Биометрия зависит от устройства.

## Первый тест

1. Создайте заметку, привычку и будущий день рождения. Перезапустите приложение: записи должны сохраниться.
2. Поставьте таймер на минуту и ближайшее напоминание. Проверьте уведомления после сворачивания. Ограничения батареи и разрешений могут задерживать сигнал.
3. Выберите провайдера и модель, введите свой ключ и отправьте короткий запрос. После перезапуска ключ вводится заново; запрос может тарифицироваться.
4. Создайте тестовый сейф и сверните приложение: повторное открытие должно требовать разблокировки.
5. Проверьте ручной обмен. Измените одну заметку на обоих устройствах до следующего обмена и проверьте сохранение конфликта.
6. Экспортируйте зашифрованный сейф до опытов с удалением приложения.

Обычные данные и чаты не зашифрованы отдельным мастер-паролем; системное резервное копирование отключено. Диктовка может использовать интернет. Модель получает сообщение и контекст беседы. OpenAI используется с `store: false`, что не обещает отсутствия всех серверных журналов.

## Для разработчика

Откройте `mobile/android` в Android Studio. Нужны JDK 17, SDK 35, AGP 8.9.2 и Gradle 8.11.1. Команды: `gradle assembleDebug lintDebug`; на эмуляторе/телефоне: `gradle connectedDebugAndroidTest`. Минимальный API — 26; Gradle Wrapper пока не включён.

Справочники: [будильники Android](https://developer.android.com/develop/background-work/services/alarms), [Keystore](https://developer.android.com/privacy-and-security/keystore), [биометрия](https://developer.android.com/identity/sign-in/biometric-auth), [контекст OpenAI](https://developers.openai.com/api/docs/guides/conversation-state).
