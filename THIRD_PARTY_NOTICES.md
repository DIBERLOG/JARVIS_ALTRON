## Модели, голоса, аудио и остальные зависимости

По сообщению владельца форка, необходимые ему разрешения на голоса получены.
Рабочие модели, записи и настройки озвучки в рамках смены лицензии не менялись.
Их собственные условия и применимые отдельные разрешения сохраняются.

Библиотеки, модели, аудио, изображения и другие сторонние материалы
не перелицензируются через LICENSE.txt. Сохраняйте их исходные лицензии
и обязательные уведомления при распространении соответствующих компонентов.
Этот файл не является полным перечнем всех зависимостей сборки.

Windows-пакет включает Microsoft Visual C++ Runtime из каталога Redist установленного инструментария, а также DirectML. Это компоненты Microsoft, распространяемые на их собственных условиях, не под лицензией проекта. При пересборке используйте разрешённые к распространению файлы Redist, не случайные DLL из интернета. App-local Runtime необходимо обновлять вместе с пакетом приложения. Справочник: [распространение Visual C++](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files).
