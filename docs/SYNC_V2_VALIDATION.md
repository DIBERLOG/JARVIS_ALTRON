# Sync v2 LAB — проверка 12 октября 2026

Ветка `codex/sync-v2-security`. Проверки использовали только временные профили и вымышленные секреты. Рабочая стабильная установка не обновлялась.

## Результаты

- Ядро Rust: 34 успешных теста, 1 пропущен. Проверены атомарность снимка/очереди/курсора, конфликты, tombstones, повторы, перезапуск, ротация и постоянный уникальный идентификатор relay.
- Windows recovery smoke: отдельные процессы и новые записи Credential Store; старый исходный файл сохранён побайтно, неверный пароль не создаёт журнал, новый профиль имеет другой системный ключ. Восстановлены вымышленные API-ключ, контейнер сейфа, неизвестные поля settings и очередь истории. Тестовые credentials удалены.
- GUI: проверки команд, TLS с закреплённым сертификатом и отказом до передачи bearer при чужом сертификате. Отдельный тест реального сетевого обработчика с тремя журналами, шифротекстом Android, повтором 10 раз, конфликтом, отзывом, ротацией и отказом при неверном AAD.
- Android: 10 instrumentation-тестов прошли в собственном новом эмуляторе `emulator-5580`, отдельный applicationId. Включены настоящие SQLite/Keystore, автономная работа трёх профилей, повтор, конфликт удаления, восстановление, шифротекст Rust → Java и пароль Unicode. Шифротекст, созданный Java, также принят тестом Rust.
- Frontend: production-сборка и DOM-проверка обязательной подготовки, очистки пароля, явного запуска, подтверждения сопряжения и согласия на сейф.
- Android release/debug/test APK и lintRelease собраны. Lint: 0 ошибок, 10 предупреждений. Release APK проверен apksigner, схема v2, постоянный отдельный LAB-сертификат.
- Windows release: отдельные `jarvis-app-sync-v2-lab` и `jarvis-gui-sync-v2-lab`. Комплект проверяется ранним smoke-режимом без инициализации профиля; NSIS создаёт отдельный пользовательский установщик.

Логи проверок находятся в игнорируемом `target/sync-v2-*.log`. Предупреждения Rust, доступности старого интерфейса и размера frontend chunks остаются; это не ошибки сборки. Для локального Gradle использован временный build-only Java-agent из-за занятых системных UDP-портов. Он не входит в APK и не изменяет системные настройки.

## Границы результата

Подключены пользовательские сохранения desktop/Android, LAN v2, долговечный зашифрованный relay, desktop-клиент, подтверждённая выдача ключей, восстановление, отзыв и ротация. На одной группе используется один активный хаб. Восстановленный хаб получает новый идентификатор relay и меняет транспортный ключ; повторное сопряжение заменяет старый токен. После изменения ключей требуется свежая копия восстановления.

Временный профиль с новым системным ключом проверен; установка на чистой Windows VM ещё не проверена. Не проверены реальные ПК + второй ПК + телефон в Wi-Fi, Android фон/уведомления/биометрия, реальные macOS Keychain/Linux Secret Service. Независимый аудит безопасности не выполнен. Поэтому сборки предназначены для тестовых данных, а не для миграции реального сейфа.

Старые plaintext-backup, логи и localStorage сохранены. Будущая история запросов desktop хранится защищённо. Текстовые экспорты остаются открытыми, если пользователь выбирает текстовый формат.

Установка и сценарии: [SYNC_V2_LAB_TESTING.md](SYNC_V2_LAB_TESTING.md). Контрольные суммы готовых EXE/APK: `artifacts/sync-v2-lab/SHA256SUMS.txt`.

## Исправление запуска голосового ядра, 13 октября 2026

В комплекте Windows обнаружена устаревшая `libpv_recorder.dll`: закреплённая Rust-зависимость PvRecorder не могла загрузить её функции, поэтому ядро завершалось до запуска IPC. Библиотека в `lib/windows/amd64` заменена файлом из той же закреплённой зависимости (`pvrecorder`, commit `33dfcdf7ae121dd4ff5b1b1ed61eda43e5f85b7f`). Обновлён запущенный тестовый комплект `windows-1.1.0-instructions`. Проверено: процесс ядра остаётся запущенным, IPC слушает порт 9713, окно подключается и выполняет авторизованный обмен. Полная проверка голосовых команд этим запуском не подтверждается. Ранее созданные установщики этим исправлением ещё не обновлены.
