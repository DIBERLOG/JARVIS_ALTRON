# Единая панель настроек JARVIS

Настройки Windows собраны в одном пространстве с боковой навигацией: основные параметры, голос и звук, нейросеть, устройства, данные и копии, сайты и команды, дополнительные параметры и сведения о приложении. Тема, слушание и выбор микрофона находятся рядом; технические движки распознавания вынесены в дополнительные настройки.

Содержимое разделов сохраняется при переходах, поэтому несохранённые параметры и введённая модель не исчезают. Общая панель сохранения видна для основных, голосовых и дополнительных параметров. Она показывает наличие изменений, успех или ошибку записи и позволяет отменить правки. Сохранение блокируется до успешной загрузки исходных значений. Тема и горячая клавиша применяются сразу; отдельные операции моделей, данных и синхронизации сохраняют свои кнопки и обработчики.

Используются существующие API и ключи настроек. Логика синхронизации и формат пользовательского профиля не изменены. Исправлены подпись действия кнопки прослушивания и показ поля Picovoice для фактического значения `Picovoice`; запись сочетания клавиш отменяется при уходе в другой раздел. Подписки страницы освобождаются при закрытии.

## Проверки

- `npm run build`: Svelte check — 0 ошибок; существующие предупреждения проекта сохранены. Windows release собран.
- `tools/test-desktop-settings.mjs`: восемь разделов, сохранение черновика при переходах, запись прежних 15 параметров, отмена, ошибка записи, черновик модели, светлая тема, окно 680 px без горизонтального переполнения, запрет сохранения при ошибке загрузки. Все операции выполняются в headless-браузере с вымышленными значениями и подменой Tauri IPC, без записи в личный профиль.
- Скриншоты в `target/settings-*.png`: основные параметры, звук, нейросеть, устройства, дополнительные параметры, светлая тема и узкое окно.
- Обновлён существующий `artifacts/sync-v2-lab/windows-1.1.0-instructions/JARVIS-Sync-v2-LAB.exe`; предыдущая сборка сохранена рядом как `JARVIS-Sync-v2-LAB-before-settings-redesign.exe`. После обычного закрытия и запуска окно работает, настройки GUI и голосового ядра успешно загружены.
- Автоматизация реального окна не смогла открыть раздел: `coordinate input geometry is unavailable`. Поэтому визуальные и поведенческие проверки панели выполнены в изолированном браузерном стенде; реальная запись пользовательских настроек не выполнялась.

Для запуска UI-проверки нужны установленные зависимости frontend, Playwright и браузер Chromium. При внешней установке пакетов задайте `JARVIS_TEST_NODE_MODULES` (папка node_modules) и `JARVIS_TEST_CHROMIUM` (путь chrome.exe), затем выполните `node tools/test-desktop-settings.mjs`. Дополнительные пакеты в приложение не добавлены. Стенд находится в `frontend/tests/settings` и не включается в сборку приложения.
