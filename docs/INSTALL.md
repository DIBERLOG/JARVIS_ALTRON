# Установка JARVIS: пошагово

## Что доступно сейчас

Актуальный релиз 1.1.15 включает установщик Windows x64 и подписанный Android APK. Linux/macOS распространяются отдельно как экспериментальные сборки.

## Windows: установка без сборки

1. Откройте [официальный релиз 1.1.15](https://github.com/DIBERLOG/JARVIS_ALTRON/releases/tag/v1.1.15), в разделе Assets скачайте файл `JARVIS-ALTRON-1.1.15-Windows-x64-setup.exe`.
2. Запустите его на Windows 10/11 x64 и выберите язык. Установка выполняется для текущего пользователя. Для интерфейса требуется Microsoft Edge WebView2; на современных Windows он обычно уже установлен.
3. Запустите JARVIS ALTRON через созданный ярлык. Интерфейс сам запускает голосовое ядро; Rust, Node.js и Python для базового запуска не нужны.
4. Выберите микрофон и язык в настройках, разрешите доступ к микрофону в Windows. В пакет входят модели Vosk; для русского языка выберите русскую модель. Проверьте команду «Джарвис, открой калькулятор».
5. Для облачного чата добавьте свой API-ключ; локальные модели Ollama и нейроозвучка устанавливаются отдельно. Необязательные функции перечислены ниже.

Пакет не подписан коммерческим сертификатом: Windows может показывать неизвестного издателя. Проверяйте источник загрузки и SHA-256 из файла `SHA256SUMS.txt` релиза; не отключайте защиту Windows. Установка на этом компьютере не заменяет проверку на чистом ПК.

Перед обновлением сохраните результаты и закройте **оба процесса** JARVIS. Пользовательская база хранится отдельно от каталога приложения; удаление приложения не должно стирать рабочие данные. Настройки и базу всё равно следует резервировать перед обновлением.

Windows и Android скачивайте из официального релиза. Сборки Linux/macOS доступны отдельно в GitHub Actions.

## Windows: сборка для разработчика

1. Установите Git, Node.js LTS, Rust через rustup (вариант MSVC), Microsoft C++ Build Tools с компонентами «Разработка классических приложений на C++» и Windows SDK. Для интерфейса нужен WebView2 Runtime. Используйте официальные сайты поставщиков.
2. Откройте PowerShell в папке, где хотите хранить проект. Выполните:

```powershell
git clone https://github.com/DIBERLOG/JARVIS_ALTRON_CLEAN.git
cd JARVIS_ALTRON_CLEAN
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-windows.ps1
```

Эти скрипты доступны только в версии исходников, содержащей данную инструкцию; старый опубликованный тег может их не содержать. Если файл не найден, используйте ручную сборку из README. `ExecutionPolicy Bypass` применяется только к этому процессу, не меняет общую политику Windows. Сначала просмотрите скрипт.

3. Дождитесь сообщения «Готово». При первой сборке скачиваются зависимости; нужен интернет и свободное место. Не закрывайте окно. Если появилась ошибка, скопируйте её полностью, без ключей и личных данных.
4. Создайте ярлык:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/start-windows.ps1 -CreateShortcut
```

5. Запускайте JARVIS ярлыком на рабочем столе. Он запускает интерфейс и голосовое ядро. Не перемещайте папку проекта после создания ярлыка; если переместили — создайте его заново. Интерфейс завершает только ядро, которое запустил сам; ранее отдельно запущенное ядро закрывайте отдельно.
6. В настройках выберите настоящий микрофон, русский язык и доступную русскую Vosk-модель. Если модели нет, подготовьте её отдельно; скрипт модели не скачивает. Разрешите доступ к микрофону в Windows. Проверьте: «Джарвис, открой калькулятор».

### Что необязательно

- Облачный чат требует вашего API-ключа и может стоить денег. Для локального чата установите Ollama и загрузите выбранную модель.
- Python, PyTorch и веса нужны отдельным вариантам нейроозвучки, не всем функциям приложения.
- Outlook нужен только для почты; классический Outlook/Kerio настраивается по [инструкции](OUTLOOK_LOCAL.md).
- AutoHotkey нужен только командам, использующим его. Voicemod и виртуальные аудиокабели не нужны для первого запуска.

### Обновление и перенос

Сохраните результаты, сделайте резервную копию данных и закройте оба процесса. Обновите исходники без принудительного сброса своих изменений, затем повторите сборку. Скрипт не заменяет существующий каталог ресурсов, чтобы не затереть настройки. DLL обновляются из библиотек проекта.

Не переносите один EXE: нужны оба процесса, DLL, ресурсы и модели. Установщик собирается командой `powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-installer.ps1`; результат — `target/release/bundle/nsis`. Успех сборки на вашем ПК не гарантирует запуск на другом.

При сборке установщика из исходников нужен также компилятор Ahk2Exe для скриптов AutoHotkey v1: установите его вместе с AutoHotkey или задайте путь в `JARVIS_AHK_COMPILER`. В готовом установщике сценарии уже скомпилированы; обычному пользователю компилятор не нужен. Модели Vosk должны быть доступны в исходных ресурсах перед упаковкой.

## Linux и macOS

Сначала прочитайте [требования и ограничения](CROSS_PLATFORM.md). Подготовьте Rust, Node.js, системные зависимости и нативный Vosk своей архитектуры. Затем:

```bash
export VOSK_LIBRARY_DIR="/absolute/path/to/native/vosk"
bash tools/build-desktop.sh
bash tools/start-desktop.sh
```

Это запуск из исходников, не установка готового приложения. На macOS понадобятся разрешения микрофона; подпись и нотариализация не подготовлены. На Linux проверяйте звуковые зависимости и WebKitGTK. Outlook COM на этих ОС недоступен.

Для сборки установочных пакетов выполните `bash tools/package-desktop.sh` на нужной ОС. Подробные зависимости, установка пакетов и проверки описаны в [инструкции Linux/macOS](CROSS_PLATFORM.md#установочные-пакеты-linux-и-macos).

## Android

Скачайте подписанный JARVIS-Mobile-1.1.15.apk из [релиза](https://github.com/DIBERLOG/JARVIS_ALTRON/releases/tag/v1.1.15) и установите поверх прежнего приложения. Удалять старую версию не нужно. Android 8 и новее. [Установка, разрешения и синхронизация с компьютером](ANDROID.md).
