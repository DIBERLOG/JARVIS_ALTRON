# Mobile 1.1.10 — отдельные разделы проверки и команд

Постоянная подпись и пакет Sync v2 LAB сохранены, Android versionCode 13. APK устанавливается поверх текущего приложения без удаления. Обновление Windows-компаньона не требуется.

## Где найти

- **Разделы → Проверка синхронизации**: три карточки с пошаговыми сценариями ПК → телефон, телефон → ПК и обмена в обе стороны. Используются заметки «Тест ПК» и «Тест телефона». Есть переходы к настройке синхронизации и заметкам. Экран содержит инструкцию, не выдуманный статус успешного обмена.
- **Разделы → Команды компьютеру**: самостоятельный экран вместо диалогового списка внутри настроек синхронизации. Без сопряжения предлагает подключить компьютер. После сопряжения кнопка «Загрузить команды компьютера» получает настоящий разрешённый список с ПК. Выбранная команда сразу отправляется через прежний защищённый канал; доступна проверка результата последней команды. Список очищается при уходе с экрана и загружается заново по запросу. Ответ загрузки после ухода не возвращает пользователя на экран команд.
- На экране **Синхронизация** есть отдельные переходы к обоим разделам. Главная и системная кнопка назад работают на новых экранах; нижняя навигация выделяет «Разделы».

Серверные разрешения, срок команды, UUID, сертификат и протокол обмена не менялись. Голосовая отправка с телефона в этом изменении не добавлена: команды выбираются кнопками. Их набор определяется сопряжённым компьютером.

## Проверки

Release, instrumentation и lint собраны. Общий прогон на подписанном release в отдельном Android 15 эмуляторе: 46 обнаруженных проверок, 44 успешно выполнены, две необязательные пропущены. Проверены переходы домой и назад во всех разделах, три карточки проверки, экран без сопряжения, список тестовых разрешённых команд и его очистка при уходе. Проверены снимки новых экранов. Реальные команды и реальные пользовательские данные для этих UI-проверок не отправлялись.

Пять холодных запусков подтвердили процесс, главный экран и отсутствие fatal exception. Физический обмен телефона и ПК остаётся отдельной пользовательской проверкой, описанной в новом разделе.
