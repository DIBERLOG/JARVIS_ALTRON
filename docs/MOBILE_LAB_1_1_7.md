# Mobile 1.1.7 — исправление вылета при запуске

Версия Android: 1.1.7-sync-v2-lab, versionCode 10. Прежний пакет и постоянный сертификат. Установите APK поверх 1.1.6, не удаляя приложение и не очищая его данные. Новый установщик Windows для этого исправления не нужен.

## Причина и исправление

Вылет 1.1.6 воспроизведён на стабильной Android 15 (API 35), на отдельном эмуляторе с вымышленными данными. Подписанный release APK падает в MobileTheme.bars из MainActivity.onCreate: PhoneWindow.getInsetsController обращается к ещё не созданному DecorView. На прежнем эмуляторе с тестовой Android 37 этот сценарий не падал.

Общий метод оформления системных панелей теперь сначала создаёт DecorView через getDecorView, затем получает контроллер панелей. Цвета, темы и защита данных сохраняются; сброс настроек, замена базы и обход шифрования не выполняются.

## Проверки

- До исправления: настоящий холодный запуск release APK 1.1.6 на Android 15 воспроизводит NullPointerException и завершение процесса.
- После исправления: пять холодных запусков release APK 1.1.7, при каждом проверены живой процесс и активный экран MainActivity; журнал вылетов пуст.
- Обновление 1.1.6 → 1.1.7 без удаления: сохранены вымышленные заметка, чат, зашифрованный черновик, вложение и светлая тема. Тестовая instrumentation-сборка подписана тем же LAB-ключом и проверяет настоящий release-профиль только на выделенном эмуляторе.
- Android release, тестовая сборка и lint собраны. Полный мобильный набор на подписанном release APK стабильной Android 15 прошёл: 36 обнаруженных проверок, 34 выполнены успешно; пропущены необязательная живая сетевая проверка и специальный upgrade-тест без параметра режима. Последний отдельно прошёл в режимах seed и verify до и после обновления.

На физическом телефоне пользователя повторный запуск пока не проверен. Причина воспроизведена и устранена на стабильной Android; это не подменяет проверку конкретного телефона.
