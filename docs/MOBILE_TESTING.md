# Android Mobile LAB: проверка на телефоне

Перед тестом сохраните экспорт данных ПК и зашифрованный сейф. Используйте вымышленные пароли. Не удаляйте приложение без резервной копии: тестовые APK из разных сборок могут иметь разные подписи.

## Личный центр

| Проверка | Ожидаемый результат |
| --- | --- |
| Создать две заметки, изменить одну, перезапустить | Обе записи сохранились, правка не потерялась |
| Таймер на минуту, свернуть приложение | Уведомление; если задержалось — проверить разрешения и батарею |
| Напоминание через несколько минут | Уведомление с нужным текстом; выполненное не уведомляет повторно |
| День рождения на будущую дату | Год сохраняется; событие не планируется раньше первой даты |
| Привычка с целью 3, дважды нажать +1 | За сегодня 2/3; после перезапуска отметки сохранены |
| Записать тренировочный подход | Вес, повторения и дата доступны после перезапуска |
| Обновить погоду/новости, отключить интернет | Старый кэш виден; ошибка обновления понятна |
| Чат без ключа, затем с собственным ключом | Без ключа запрос не уходит; с ключом выбран правильный провайдер |
| Новый чат, вернуться в предыдущий, экспортировать | Беседы не смешиваются, экспорт содержит выбранную историю |

## Wi-Fi и конфликты

1. В новой компьютерной сборке включить обмен, сканировать QR-код, сверить и подтвердить код. До подтверждения телефон не должен получать данные.
2. Добавить заметку на телефоне, выполнить обмен, проверить на ПК. Изменить её на ПК, выполнить обмен, проверить на телефоне.
3. Удалить синхронизированную заметку и проверить удаление на втором устройстве.
4. Без промежуточного обмена по-разному изменить одну заметку на обоих устройствах. После обмена проверить конфликт и обе версии; выбор одной версии должен быть явным.
5. Включить историю отдельно: проверить перенос чатов. Выключение не должно удалять уже полученную историю.
6. Остановить сервис на ПК: обмен должен завершаться понятной ошибкой без потери локальных записей.
7. Отозвать телефон на ПК: старое подключение больше не должно получать данные. Для восстановления требуется новое сопряжение.

## Тестовый сейф

1. Создать запись с вымышленным паролем. Проверить неверный мастер-пароль: сейф не открывается.
2. Открыть запись, свернуть приложение и вернуться: требуется разблокировка, открытый пароль не остаётся на экране.
3. Экспортировать зашифрованную копию и восстановить её. Проверить запись и мастер-пароль. Не удалять исходное приложение до проверки копии.
4. Передачу сейфа разрешить отдельно на ПК и телефоне. Пароли не должны появляться в обычном экспорте заметок/чатов.
5. Использовать один мастер-пароль на тестовых сейфах. При разных версиях выполнить предложенное объединение; конфликтующие карточки проверить вручную.
6. Оставить сейф открытым на ПК, изменить его через телефон и синхронизировать. Попытка сохранения старой версии на ПК должна быть отклонена, а не перезаписать новый файл.
7. Если доступна биометрия, включить её, заблокировать и проверить отпечаток. Отмена биометрии не открывает сейф; мастер-пароль остаётся запасным способом.

Отдельно проверьте перезагрузку телефона, запрет уведомлений, экономию батареи и смену Wi-Fi. Автотесты не подтверждают поведение конкретного производителя.
