# JARVIS ALTRON 1.1.15

Обычный релиз Windows и Android. Пометка LAB у приложения и синхронизации снята; в GitHub выпуск публикуется без статуса pre-release. Отдельные офисные функции «Агенты · LAB» и сборки Linux/macOS сохраняют собственный статус.

## Скачать

- **Android 8+** — `JARVIS-Mobile-1.1.15.apk`.
- **Windows 10/11 x64** — `JARVIS-ALTRON-1.1.15-Windows-x64-setup.exe`.
- `SHA256SUMS.txt` — контрольные суммы; `ANDROID-INSTRUCTIONS-RU.md` — установка и подключение телефона.

## Обновления

- Единая панель настроек Windows с понятными разделами и сохранением изменений.
- Подтверждение сопряжения на компьютере и телефоне, три направления обмена, отдельный экран команд ПК.
- Правильный выбор домашней сети: виртуальные адаптеры WSL/VMware не попадают в QR-код.
- Более понятные состояния подключения, ошибки и индикаторы загрузки.
- Читаемые заметки, сохранённые беседы, документы и вложения в чате, категории новостей, погода, привычки, тренировки и таймер.
- Светлая, тёмная и системная темы.

## Установка поверх предыдущей версии

Android APK подписан прежним постоянным ключом. Установите его поверх JARVIS Mobile, не удаляя приложение. Данные и сопряжения сохраняются. Идентификаторы Android/Windows и внутренние имена файлов сохранены для совместимости обновлений; они не обозначают экспериментальный статус.

На Windows закройте JARVIS перед обновлением. Для интерфейса нужен Microsoft Edge WebView2. Профиль хранится отдельно от программы; перед переустановкой сохраните резервную копию.

Для подключения: на ПК **Настройки → Устройства → Включить обмен**, на телефоне отсканируйте QR-код, сравните код и подтвердите на обоих устройствах. Затем нажмите **«Синхронизировать сейчас»**. [Полная инструкция Android](../ANDROID.md).

## Проверено перед публикацией

- Android release и lintRelease, подпись APK, обновление поверх прежней сборки на собственном эмуляторе Android 15.
- Полный инструментальный прогон: `OK (49 tests)` — 46 выполнены, три требуют отдельных фикстур и пропущены.
- Пять холодных запусков без FATAL EXCEPTION.
- Frontend/Svelte и Windows release, сборка установщика NSIS.
- Изолированные UI-проверки настроек: навигация, черновики, сохранение, отмена, ошибки, светлая тема и узкое окно.
- Пользователь подтвердил работу текущих функций и синхронизации на своих устройствах.

Проверки не являются независимым аудитом безопасности или проверкой всех моделей телефонов. Подпись APK не меняется; закрытый ключ, API-ключи, личные профили и резервные копии в релиз не входят.
