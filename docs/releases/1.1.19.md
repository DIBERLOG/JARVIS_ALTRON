# JARVIS ALTRON 1.1.19 — один установщик и свой голос

Достаточно скачать один `.exe`. Остальное Джарвис подготовит сам.

**Установка и первый запуск**
- Если в Windows нет Microsoft Edge WebView2, установщик поставит его сам.
- При первом запуске Джарвис в фоне докачивает голос Fish S2: голосовой сервер и модель, около 6,4 ГБ. Для этого голоса нужна видеокарта с 8 ГБ памяти, на более слабых ПК остаётся системный голос.
- Так же в фоне докачиваются локальный ИИ Ollama и модели qwen3:4b-instruct и qwen3:8b, около 11 ГБ. С ними работают чат, перевод и обработка текста без API-ключа.
- Прогресс виден в «Настройки → Голос и звук». Оборванная загрузка продолжается с того же места. Пока она идёт, Джарвис работает и говорит системным голосом.

**Голос**
- Голос Fish S2 встроен в приложение и больше не требует Python.
- Длинные ответы озвучиваются по предложениям: речь начинается через несколько секунд.
- Голосовая модель освобождает память после 10 минут простоя и закрывается вместе с Джарвисом.
- «Стоп», «хватит», «замолчи» сразу прерывают речь.
- Вывод через Voicemod теперь по умолчанию выключен.

**Команды**
- В разделе «Сайты и команды» можно добавлять свои голосовые команды: открыть программу или сайт по своей фразе.
- Джарвис понимает больше формулировок и ошибок распознавания:
  - «через полчаса», «в шесть вечера»;
  - «покажи идею про…»;
  - вопросы о новостях по теме.
- «Какие планы» отвечает только о ваших делах, без погоды и новостей.
- Новости читаются по заголовкам, без ссылок и служебных символов.
- Слово «Джарвис» распознаётся, даже если в системе по умолчанию выбран виртуальный микрофон.

**Интерфейс**
- Убраны подсказки на главной и всплывающий текст ответа над Центром.
- Аккуратнее оформлен флажок «Ежедневно» в напоминаниях.
- Карточки состояния показывают реальный голос и микрофон.

Android-приложение не менялось: в релиз вложен прежний подписанный JARVIS Mobile 1.1.18.

Установщик не подписан, поэтому Windows может показать предупреждение SmartScreen. Сверяйте SHA-256 по SHA256SUMS.txt. Модель голоса Fish Audio S2 Pro распространяется по некоммерческой исследовательской лицензии. Модель и Ollama скачиваются с Hugging Face, GitHub и ollama.com.
