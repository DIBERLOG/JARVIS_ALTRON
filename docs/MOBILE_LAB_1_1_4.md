# JARVIS Mobile 1.1.4 · Sync v2 LAB

Android: versionCode 7, прежний пакет и постоянная подпись LAB. Windows-компаньон остаётся версии 1.1.0 Sync v2 LAB, но оба его процесса обновлены для команд телефона. Стабильная Windows v1.0.0 не заменяется.

## Изменения

- Новости загружаются при смене категории, региона и источника. Ответ прежней категории не отображается под новой; при ошибке старая лента не выдаётся за выбранную.
- Дни рождения создаются и редактируются через календарь Android. Существующие метаданные записи сохраняются.
- Круглая отметка привычки с галочкой и отдельный крестик архива имеют область нажатия 48 × 48. История архивированной привычки сохраняется.
- Погода: отдельный значок переменной облачности, значки на графике, максимум и минимум разными цветами, дни недели, выбор дня с температурой и рекомендация одежды.

## Команды компьютеру

1. Установите обновлённый LAB-компаньон из комплекта Mobile 1.1.4. Старый компаньон этого API не имеет.
2. Включите JARVIS и обмен на ПК; выполните обычное подтверждённое QR-сопряжение. Существующее сопряжение LAB можно сохранить.
3. На телефоне: **Синхронизация → Команды компьютеру**. Список приходит от ПК. Нажатие выполняет разрешённую команду сразу.
4. **Проверить результат** показывает выполнение приложения, показ раздела либо неизвестный результат. Последний запрос можно проверить, снова открыв список команд.

Доступны открытие разделов Центра, браузера, YouTube, ChatGPT, Google, калькулятора, Telegram, Discord, VS Code и сворачивание/восстановление окон, если команды есть в каталоге этого ПК. Произвольный текст, аргументы консоли, перезагрузка, повтор последней команды и удаление данных не принимаются. API-ключи и пароли не передаются. Открытие раздела с телефона отклоняется, если на ПК есть несохранённая заметка.

Канал использует существующие private-LAN TLS, точную привязку сертификата и токен одобренного устройства; секрет QR не разрешает команды. Отзыв устройства и незавершённая ротация блокируют доступ. Каждый запрос имеет UUID и срок не более минуты. Квитанция сохраняется зашифрованной до ACK, а отметка передачи ядру — до фактической отправки. Повтор идентичного пакета не выполняет команду повторно. Сетевой обрыв/перезапуск после передачи может оставить неизвестный результат; автоматического повтора нет. Это отдельный канал живого управления, не очередь офлайн-данных синхронизации.

## Проверки и ограничения

Проверены сборки Android release/debug, Android lint, 25 Android-тестов, включая круглые кнопки, сохранение отметки и график на вымышленных данных. Проверены 6 Rust-тестов LAN-шлюза, включая трёх клиентов, отзыв, 10 повторов команды, перезапуск квитанций, чужой токен, изменённый UUID-пакет, срок и запрещённую команду. Frontend: 0 ошибок, существующие предупреждения. Windows release собирается с обоими обновлёнными процессами и исправленной DLL рекордера.

Физический телефон, выполнение команд через реальный Wi-Fi, уведомления Android в фоне и настоящий отпечаток требуют проверки пользователем. Успешная сборка и тесты эмулятора не подтверждают эти сценарии. Реальные пользовательские профили при тестах не изменялись. Полная стабильность синхронизации на всех физических устройствах не объявляется.
