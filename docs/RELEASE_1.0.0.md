# JARVIS ALTRON 1.0.0 · Release

Первый Windows-выпуск с установщиком. Для Windows 10/11 x64 скачайте файл `JARVIS ALTRON_1.0.0_x64-setup.exe` из Assets и установите приложение для текущего пользователя. Если WebView2 отсутствует, нужен интернет для его установки.

## Главное

- Версия 1.0.0 и отметка Release в интерфейсе, обновлённый логотип.
- Windows-установщик: интерфейс, голосовое ядро, DLL, модели Vosk и ресурсы команд.
- Интерфейс автоматически запускает ядро и завершает только запущенный им процесс при выходе.
- OpenAI и DeepSeek, локальные модели, история чатов и экспорт.
- «Агенты · LAB»: документы, цепочки, проверка результатов, форматирование и экспорт, включая DOCX.
- Outlook/Kerio: голосовые черновики, проверка перед отправкой и защита от повторной отправки.
- Личный Центр, напоминания, заметки, задачи и сайт расписания; обновлённые инструкции.

## Ограничения

Linux/macOS и сокращённый Android Mobile LAB включены только как экспериментальные исходники. Готовых пакетов и подтверждённой поддержки этих ОС пока нет; адаптацию будем развивать отдельно.

«Агенты · LAB» и Microsoft 365 остаются экспериментальными. Облачные запросы могут тарифицироваться; нужны собственные ключи. Локальная Ollama, нейроозвучка и её Python-зависимости не входят в установщик. Базовая озвучка использует установленный системный голос Windows; его язык зависит от системы.

Пакет не подписан цифровым сертификатом. Проверьте официальный источник и SHA-256 по `SHA256SUMS.txt`; не отключайте защиту Windows. Перед обновлением сохраните данные и закройте оба процесса. Проверка на машине разработчика не заменяет установку на чистом ПК и ручной тест микрофона/почты.
