# Повседневные голосовые команды

После активации Джарвиса произнесите команду. Окно приложения должно быть запущено: обработчики используют Личный центр. Можно добавлять «пожалуйста» или «можешь»; параметры после команды сохраняются.

| Навык | Команды | Реальная обработка |
|---|---|---|
| Обзор дня | Что у меня сегодня? / Утренний обзор | Напоминания на сегодня, незавершённые дела, погода, до трёх новостей. Ошибка одного сервиса не скрывает остальные данные. |
| Погода | Вечером нужен зонт? / Завтра нужен зонт? / Как одеться сегодня? | Прогноз сохранённого города, температуры и рекомендации. Для вечера используются почасовые данные 18–23 часов по времени города. Если их нет, ответ явно говорит о прогнозе за весь день. |
| Новости | Что нового в технологиях за сегодня? / Расскажи новости / Подробнее о второй новости | Заголовки, выдержки RSS, источники и ссылки. Темы: технологии, нейросети, игры, наука, спорт, космос. «Сегодня» фильтрует дату публикации. Подробности — из последней полученной подборки, не полный текст статьи. |
| Идеи | Запомни идею: добавить управление музыкой / Какие идеи для проекта я записывал? / Найди заметку про музыку | Сохранение текста, заголовка и даты в существующие заметки; поиск по тексту и названию. |
| Напоминания | Через сорок минут напомни выключить духовку | Сохранённое напоминание с точным временем. Уведомление требует работающего приложения. Старый пошаговый сценарий «создай напоминание» сохранён. |
| Покупки и дела | Добавь молоко и хлеб в покупки / Прочитай список покупок / Отметь молоко купленным / Добавь отправить отчёт в список дел | Чек-листы «Покупки» и «Дела» в заметках. Повторный активный пункт не дублируется. |
| Файлы | Найди документ с курсовой, который я вчера редактировал / Покажи файл номер один | Поиск по имени и дате изменения в Documents, Downloads, Desktop. Не индексирует содержимое; результаты ограничены 20 файлами и 30 000 просмотренных записей. Открывает папку выбранного файла. |
| Текст | Переведи это / Объясни проще / Сократи это / Исправь ошибки в тексте | Выделите фрагмент в любом окне: Джарвис сам копирует выделение (Ctrl+C) и проверяет, что буфер обмена изменился. В терминалах и в собственном окне выделение не копируется — там Ctrl+C прервал бы программу; используется уже скопированный текст. До 12 000 символов, обрабатывает настроенный провайдер модели. Исходный документ не меняется. |
| Работа | Включи режим работы | Запускает установленный VS Code и открывает Яндекс Музыку в браузере. Воспроизведение на сайте может потребовать нажатия кнопки. |
| Вход на сайты | Открой вход в GitHub / Войди в Google / Зайди в аккаунт Discord | Открывает страницу входа из фиксированного списка: GitHub, GitLab, Google, Яндекс, ВКонтакте, Telegram, Discord, Steam, Twitch, YouTube, Microsoft, ChatGPT, Notion, Figma, Госуслуги. Логин и пароль подставляет менеджер паролей браузера после разблокировки; Джарвис их не видит, не диктует и не хранит. Распознанная речь никогда не попадает в адрес. |

## Умное распознавание

Команду не нужно произносить дословно. Голосовое ядро (`crates/jarvis-core/src/commands/smart.rs`) сводит свободную формулировку к одной каноничной фразе, которую понимают обработчики:

- **Запросы без записи** — обзор дня, погода, новости, чтение списков, режим работы, обработка текста — подбираются по похожести на десятки примеров: сравниваются основы слов, лишние слова почти не мешают, опечатки распознавания в одну букву допускаются («севодня», «зондик»). Если два запроса подходят почти одинаково, Джарвис не угадывает.
- **Запросы с записью** — идеи, напоминания, покупки, дела — срабатывают только по явным шаблонам, зато шаблонов много: «напомни позвонить маме через час», «добавь в покупки молоко», «надо купить яйца», «вычеркни молоко из покупок», «у меня идея: …». Обычный разговор не превращается в сохранённую запись.
- Фразы установленных пакетов команд не перехватываются — это проверяет тест. В режиме разговора с нейросетью подбор выключен: «объясни это» остаётся вопросом ассистенту.

Примеры: «какие у меня планы на сегодня» → обзор дня; «будет ли дождь вечером» → вечерний прогноз; «последние новости про космос» → новости о космосе; «сделай короче» → сокращение текста; «где лежит файл бюджет» → поиск файла.

Существующее хранилище паролей Личного центра не изменено.

## Озвучка

Погодный Lua-сценарий сначала ищет запись `weather_<температура>`. Если её нет, включает запись общего ответа и синтезатор речи. В установленной копии не было `TrainedXttsSpeak.py` и указателя `trained-checkpoint.txt`, поэтому XTTS заменялся на Silero/eugene. Дополнительно выбор синтезатора читал зашифрованный файл настроек как обычный JSON, игнорируя сохранённый режим. Исправлен выбор через штатное чтение настроек; `resources/tts` добавлены в упаковку ресурсов. Нейронная модель и её контрольная точка остаются локальными и не включаются в репозиторий.
