# Голосовые команды VPN на ПК

После «Джарвис» произнесите:

| Команда | Действие |
| --- | --- |
| «Открой ВПН» / «Открой хэпп» | Открывает установленный Happ |
| «Перезапусти ВПН» / «Перезапусти хэпп» | Закрывает и снова запускает приложение Happ |
| «Открой клаудфлер» / «Открой варп» | Открывает Cloudflare One Client |
| «Переподключи клаудфлер» / «Перезапусти варп» | Выполняет штатные disconnect → connect и открывает Cloudflare |

Общие фразы «ВПН» относятся к Happ. Открытие окна не означает включение туннеля. После перезапуска Happ восстановление подключения зависит от его настройки автоподключения. Профили, подписки и настройки VPN не изменяются. Клиенты друг друга не закрывают.

Используются установленные приложения из стандартных папок Program Files. Перезапуск Happ ограничен точным путём EXE и текущим пользовательским сеансом; сначала запрашивается обычное закрытие окна, затем при необходимости завершается этот процесс. Системные службы и посторонние процессы не завершаются. Для Cloudflare используется собственная warp-cli, без перезапуска системной службы и повышения прав. Если клиент отклонит операцию, JARVIS покажет понятную ошибку.

Штатный интерфейс описан в [документации Cloudflare](https://developers.cloudflare.com/cloudflare-one/team-and-resources/devices/cloudflare-one-client/). Наличие connect/disconnect дополнительно проверено через --help установленной утилиты.

Проверка помощника запуска выполнена с подставными процессами: запуск, перезапуск остановленного/работающего Happ, последовательность Cloudflare и отказ. Настоящие VPN во время теста не отключались. Проверку голосового распознавания и фактического восстановления вашего соединения выполните на ПК.
